8

CSS Custom Property Sync

All Figma variables are mirrored as CSS custom properties in spectrum-variables.css, following the --spectrum-sys-[category]-[name] convention.

/* Colours */
--spectrum-sys-color-primary: #0070d2;
--spectrum-sys-color-on-primary: #ffffff;

/* Typescale (90 vars) */
--spectrum-sys-typescale-display-large-size: 57px;

/* Shape (10 vars) */
--spectrum-sys-shape-corner-medium: 12px;
Existing property names are preserved; new ones are added alongside them.
