# 🔗 Spectrum Chip Dependencies

This document shows the dependency relationships for the spectrum-chip component and how it integrates with other components in the Spectrum system.

---

## 📋 Component Usage Overview

**spectrum-chip** is a foundational atomic component used by 2 other components in the system. It provides consistent interactive behavior, selection states, and accessibility across all chip implementations.

### Components Using spectrum-chip

- **spectrum-accordion** (chip variant triggers)
- **spectrum-conversation-panel** (interactive tags and citations)

## 📦 Integration Patterns

### Chip Integration Pattern
Multiple components use spectrum-chip as internal interactive element:
- Properties pass through directly: `variant`, `label`, `selected`, `disabled`
- Chip handles all visual states (hover, focus, active, selected) and animations
- Parent wrapper provides context and event handling

### Usage Examples in Dependent Components

#### spectrum-accordion
```html
<spectrum-chip
  variant="primary"
  label="Section Title"
  leading-icon="keyboard_arrow_down"
  @chipAction=${this.handleToggle}>
</spectrum-chip>
```

#### spectrum-conversation-panel
```html
<spectrum-chip
  variant="input" 
  label="Source Citation"
  show-trailing-icon="true"
  @chipAction=${this.handleTagAction}>
</spectrum-chip>
```
