## 🏗️ Architecture Integration

### SpectrumChip Integration Pattern
The spectrum-chip component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() debug?: boolean;
  @Prop() variant?: 'primary' | 'secondary' | 'assist' | 'filter' | 'input' | 'suggestion';
  @Prop() size?: 'small' | 'medium' | 'large' | 'extra-small';

  render() {
    return (
      <div class="example-component">
        <spectrum-chip
          debug={this.debug}
          variant={this.variant}
        >
          Component Content
        </spectrum-chip>
      </div>
    );
  }
}
```
