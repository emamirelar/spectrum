# 🔗 Spectrum Chip Dependencies

This document shows the dependency relationships for the spectrum-chip component and how it integrates with other components in the Spectrum system.

---

## 📋 Component Usage Overview

**spectrum-chip** is a Level 1 atomic component with no internal dependencies. It provides compact, interactive elements for tags, filters, and selections, serving as a fundamental building block for 2 higher-level components that require micro-interaction elements.

### Dependencies
- **None** (pure atomic component)

### Components Using spectrum-chip

- **spectrum-accordion** (expandable content triggers and chip-based interactions)
- **spectrum-conversation-panel** (message tags, interactive content elements, and user-generated content organization)

## 🏗️ Architecture Integration

### Chip Integration Pattern
The chip component follows a consistent integration pattern across dependent components:

```typescript
// Common integration pattern in dependent components
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'spectrum-example-component'
})
export class ExampleComponent {
  @Prop() chipVariant?: 'primary' | 'secondary' | 'assist' | 'filter' | 'input' | 'suggestion' = 'primary';
  @Prop() chipSize?: 'extra-small' | 'small' | 'medium' | 'large' = 'medium';
  @Prop() disabled?: boolean = false;

  render() {
    return (
      <div class="example-component">
        <spectrum-chip
          variant={this.chipVariant}
          size={this.chipSize}
          label="Interactive Element"
          disabled={this.disabled}
          onClick={this.handleChipClick}
        />
      </div>
    );
  }

  private handleChipClick = () => {
    // Component-specific logic
  };
}
```

### Property Pass-Through Pattern
Dependent components typically pass through chip properties:

```typescript
// spectrum-accordion example
<spectrum-chip
  variant={this.chipVariant || 'assist'}

  label={this.label}
```


## 🔄 Event Flow

### Standard Chip Events
1. User interaction (click, keyboard activation)
2. Chip emits standardized chipAction events
3. Parent component receives and processes events
4. Parent may emit its own events with context

### Integration Event Examples

#### Accordion Integration
```typescript
// Chip interaction in accordion
onChipAction(event: CustomEvent) {
  this.accordionToggle.emit({
    action: 'expand-via-chip',
    expanded: !this.expanded,
    source: 'chip-trigger',
    chipAction: event.detail.action
  });
}
```

#### Conversation Panel Integration
```typescript
// Tag chip interaction in conversation panel
onTagChipAction(event: CustomEvent) {
  this.tagAction.emit({
    action: event.detail.action,
    source: 'conversation-panel',
    tagLabel: event.detail.label,
    context: { messageId: this.messageId }
  });
}
```

### Required Setup
```typescript
// No additional imports required - chip is self-contained
import 'spectrum-chip';
```

### Common Integration Patterns

#### 1. Trigger Pattern (spectrum-accordion)
```typescript
// Chip serves as an interactive trigger for larger component actions
<spectrum-chip 
  variant="assist"
  label={this.label}
  onClick={this.toggleExpansion}
  class="accordion__chip-trigger">
</spectrum-chip>
```

#### 2. Tag Pattern (spectrum-conversation-panel)
```typescript
// Chip represents user-generated or system-generated tags
<spectrum-chip
  variant="input"

  showTrailingIcon={true}

  action="remove-tag">
</spectrum-chip>
```

#### 3. Filter Pattern (Future Integration)
```typescript
// Chip used for filtering and categorization
```

### Conversation Panel → Chip Integration
```typescript

class SpectrumConversationPanel {
  @State() messageTags: Array<{id: string, label: string}> = [];
  
  render() {
    return (
      <div class="conversation-panel">
        <div class="message-tags">
          {this.messageTags.map(tag => (
            <spectrum-chip
              variant="input"
              label={tag.label}
              showTrailingIcon={true}
              onClick={() => this.removeTag(tag.id)}
            />
          ))}
        </div>
        {/* Message content */}
      </div>
    );
  }
}
```

## 🎯 Integration Best Practices

### Event Handling
- Always include meaningful action values in chip events
- Use chip events to trigger parent component state changes
- Implement proper event bubbling for complex component hierarchies

### Styling Coordination
- Use CSS custom properties to coordinate chip styling with parent components
- Ensure chip colors work with parent component backgrounds
- Maintain consistent spacing and alignment with parent layouts

### Accessibility Integration
- Ensure chip focus management works within parent component focus flows
- Provide appropriate ARIA labels that describe chip function within context
- Test keyboard navigation across chip → parent component boundaries

### Performance Optimization
- Use efficient event handling for chip interactions in lists
- Implement proper cleanup for chip event listeners
- Consider virtualization for large chip collections
