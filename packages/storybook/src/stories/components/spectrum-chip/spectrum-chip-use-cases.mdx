## Performance Optimization Patterns

### Large Dataset Handling
**Business Context:** Applications with thousands of filterable items need efficient chip management.

```javascript
// Efficient chip rendering for large datasets
const FilterChipList = ({ filters, onFilterChange }) => {
  const [visibleFilters, setVisibleFilters] = useState(filters.slice(0, 10));
  
  return html`
    <div class="filter-container">
      ${visibleFilters.map(filter => html`
        <spectrum-chip
          variant="filter"
          label="${filter.label} (${filter.count})"
          .selected=${filter.selected}
          @chipAction=${(e) => onFilterChange(filter.id, e.detail)}
        ></spectrum-chip>
      `)}
      
      ${filters.length > 10 ? html`
        <spectrum-chip
          variant="secondary"
          label="Show More (${filters.length - 10})"
          leadingIcon="expand_more"
          @chipAction=${() => setVisibleFilters(filters)}
        ></spectrum-chip>
      ` : ''}
    </div>
  `;
};
```
