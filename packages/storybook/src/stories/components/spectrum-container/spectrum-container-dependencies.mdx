## 🏗️ Architecture Integration

### SpectrumContainer Integration Pattern
The spectrum-container component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() size?: 'xs' | 'sm' | 'md' | 'lg' | 'xl' | 'full' | 'fluid';
  @Prop() maxWidth?: string;
  @Prop() padding?: 'none' | 'xs' | 'sm' | 'md' | 'lg' | 'xl';

  render() {
    return (
      <div class="example-component">
        <spectrum-container
          size={this.size}
          maxWidth={this.maxWidth}
        >
          Component Content
        </spectrum-container>
      </div>
    );
  }
}
```
