### Dependencies

### Components Using spectrum-avatar
- **None currently** (foundational component available for use by other components)

## 🏗️ Architecture Integration

### Component Layer: Level 1 (Atomic)
The spectrum-avatar component serves as a foundational atomic component in the Spectrum Design System:

```
Level 0: Foundation (Theme, Color System)
Level 1: Atomic Components ← spectrum-avatar
Level 2: Composed Components (can use spectrum-avatar)
Level 3: Complex Components (can use spectrum-avatar)
```

### Integration Opportunities

The avatar component is designed to be integrated into higher-level components such as:

- **User Lists**: Display team members with status indicators
- **Chat Systems**: Show message authors and participants
- **Profile Headers**: Primary user identification
- **Navigation Components**: User account representation
- **Activity Feeds**: Content attribution and authorship
- **Comment Systems**: Author identification
- **Team Dashboards**: Member presence and status

## 🔄 Event System Integration

### Events Emitted
- `avatarAction`: Primary interaction event when avatar is clicked

### Event Pattern
```typescript
interface AvatarActionEvent {
  action?: string;    // Action identifier (e.g., 'profile-click', 'view-details')
  label?: string;     // User-friendly label
  id?: string;        // Unique identifier for the avatar
}
```

### Example Integration
```html
<spectrum-avatar
  label="John Doe"
  clickable="true"
  action="view-profile"
  @avatarAction=${(e) => handleUserProfileClick(e.detail)}
></spectrum-avatar>
```

## 📚 Integration Guidelines

### Best Practices for Using Avatar in Other Components

#### 1. Event Forwarding
```typescript
// In a parent component
@Listen('avatarAction')
handleAvatarAction(event: CustomEvent<AvatarActionEvent>) {
  // Forward with additional context
  this.userInteraction.emit({
    action: event.detail.action,
    userId: event.detail.id,
    source: 'avatar-click',
    timestamp: Date.now()
  });
}
```

#### 2. Property Binding
```html
<!-- Dynamic property binding from parent data -->
<spectrum-avatar
  .src=${user.profileImage}
  .label=${user.displayName}
  .avatarId=${user.id}
  .showStatus=${this.enableStatusIndicators}
  .status=${user.onlineStatus}
  .clickable=${this.allowUserInteraction}
  .size=${this.interfaceDensity}
></spectrum-avatar>
```

#### 3. Accessibility Integration
```typescript
// Ensure proper ARIA integration in parent components
renderUserProfile() {
  return html`
    <section role="region" aria-labelledby="user-profile-heading">
      <h2 id="user-profile-heading">User Profile</h2>
      <spectrum-avatar
        .label=${this.user.name}
        .src=${this.user.avatar}
        clickable="true"
        action="edit-profile"
        aria-describedby="profile-description"
      ></spectrum-avatar>
      <p id="profile-description">Click avatar to edit profile</p>
    </section>
  `;
}
```

### Testing Integration
```typescript
// Test avatar integration in parent components
it('should handle avatar clicks correctly', async () => {
  const page = await newE2EPage();
  await page.setContent(`
    <my-component>
      <spectrum-avatar 
        label="Test User" 
        clickable="true"
        action="test-action"
      ></spectrum-avatar>
    </my-component>
  `);
  
  const avatarAction = await page.spyOnEvent('avatarAction');
  const avatar = await page.find('spectrum-avatar');
  
  await avatar.click();
  expect(avatarAction).toHaveReceivedEventDetail({
    action: 'test-action',
    label: 'Test User'
  });
});
```

## 📈 Performance Considerations

### Component Integration Impact
- **Memory**: Minimal footprint (~2KB compressed)
- **Rendering**: Optimized for frequent updates
- **Image Loading**: Built-in lazy loading and error handling
- **Color Generation**: Cached initials color calculations

### Best Practices for Large Lists
```html
<!-- Use smaller sizes for list views -->
<spectrum-avatar
  size="sm"
  .label=${user.name}
  .avatarId=${user.id}
></spectrum-avatar>

<!-- Avoid large images in repetitive contexts -->
<spectrum-avatar
  .label=${user.name}
  .showStatus=${false}
  size="xs"
></spectrum-avatar>
```
