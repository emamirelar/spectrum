# 🔗 Spectrum Context Menu Dependencies

This document shows the dependency relationships for the spectrum-context-menu component and how it integrates with other components in the Spectrum system.

---

## 📋 Component Usage Overview

**spectrum-context-menu** is a Level 1 atomic component with no internal dependencies. It provides foundational context menu functionality and exports interfaces used by 2 other components in the system.

### Dependencies
- **None** (atomic component)

### Components Using spectrum-context-menu

- **spectrum-collapsible-list** (imports ContextMenuAction interface)
- **spectrum-rail** (imports ContextMenuAction interface)

### Exported Interfaces
- **ContextMenuAction** - TypeScript interface for menu action definitions

## 🏗️ Architecture Integration

### Interface Export Pattern
```typescript
// spectrum-context-menu exports TypeScript interface
export interface ContextMenuAction {
  label: string;
  action: string;
  icon?: string;
  shortcut?: string;
  disabled?: boolean;
  danger?: boolean;
  separator?: boolean;
  submenu?: ContextMenuAction[];
}
```

### Consumer Integration Examples

#### Collapsible List Integration
```typescript
// spectrum-collapsible-list imports and uses the interface
import { ContextMenuAction } from '../spectrum-context-menu/spectrum-context-menu';

class SpectrumCollapsibleList {
  private contextMenuActions: ContextMenuAction[] = [
    { label: 'Rename', action: 'rename', icon: 'edit' },
    { label: 'Delete', action: 'delete', icon: 'delete', danger: true },
    { label: 'Copy', action: 'copy', icon: 'content_copy' }
  ];
}
```

#### Rail Integration
```typescript

  private moreMenuActions: ContextMenuAction[] = [
    { label: 'Settings', action: 'settings', icon: 'settings' },
    { label: 'Help', action: 'help', icon: 'help' },
```

## 🔄 Event Flow

### Standard Context Menu Flow
1. User triggers context menu (right-click, button click, etc.)
2. `spectrum-context-menu` creates menu overlay
3. Menu items defined using `ContextMenuAction` interface
4. User selects menu item
5. Menu emits `menuAction` event with action details
6. Parent component handles action

### Integration Event Flow
1. **spectrum-collapsible-list** or **spectrum-rail** creates context menu
2. Menu actions conform to `ContextMenuAction` interface
3. Menu events bubble up to parent component
4. Parent components coordinate with their own event systems
5. Consistent action patterns across all menu implementations

## 🔧 Development Considerations

### When Modifying spectrum-context-menu

#### Interface Changes (Breaking)
1. **Review all consumers** - spectrum-collapsible-list and spectrum-rail
2. **Plan migration strategy** - Update interface and all imports simultaneously
3. **Test integration points** - Verify menu behavior in both components
4. **Update documentation** - Keep interface documentation current

#### Implementation Changes (Non-Breaking)
1. **Test positioning logic** - Ensure smart positioning still works
2. **Verify accessibility** - Maintain keyboard navigation and screen reader support
3. **Check performance** - Large menus should remain responsive
4. **Validate styling** - CSS custom properties should remain functional

### When Consuming spectrum-context-menu

#### New Component Integration
```typescript
// Import the interface for type safety
import { ContextMenuAction } from '../spectrum-context-menu/spectrum-context-menu';

// Define actions using the interface
const actions: ContextMenuAction[] = [
  { label: 'Action', action: 'my-action', icon: 'my-icon' }
];

// Create menu and handle events
const menu = document.createElement('spectrum-context-menu');
menu.addEventListener('menuAction', handleMenuAction);
```

#### Best Practices
1. **Always use ContextMenuAction interface** - Ensures type safety
2. **Handle all action types** - Include proper switch/case for all actions
3. **Provide meaningful labels** - Use clear, actionable text
4. **Include appropriate icons** - Visual context improves usability
5. **Mark dangerous actions** - Use `danger: true` for destructive actions

## 🛠️ Implementation Notes

### Required Exports
```typescript

export interface ContextMenuAction { /* ... */ }
export { SpectrumContextMenu };
```

### Consumer Requirements
- Import `ContextMenuAction` interface for type safety
- Handle `menuAction` events with proper action dispatching
- Provide accessible trigger mechanisms
- Follow positioning guidelines for optimal UX

### Performance Considerations
- Context menu creation is lightweight (no heavy dependencies)
- Menu rendering is lazy (only when shown)
- Event delegation minimizes memory usage
- CSS positioning uses transform for GPU acceleration
