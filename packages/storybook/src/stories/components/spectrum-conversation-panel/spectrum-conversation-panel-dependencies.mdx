## Direct Dependencies

### Core Components
- **spectrum-panel**: Primary container providing layout, background levels, and title editing functionality
- **spectrum-accordion**: Used for expandable exploration sections with chip-based triggers
- **spectrum-button**: Action buttons within messages for user interactions
- **spectrum-chip**: Source citations and exploration suggestions as interactive chips

### Foundation Dependency
- **spectrum-theme**: Inherited through all child components for consistent theming and color systems

## Audio Resource Dependencies

### Sound File Requirements
- **button.mp3**: Played when action buttons are clicked
- **chip.mp3**: Played when chips (explorations, citations) are clicked
- **waiting.mp3**: Looped during loading states

### Audio Integration
```typescript
// Audio initialization
private initializeAudio() {
  this.audioElement = new Audio('./waiting.mp3');
  this.audioElement.preload = 'auto';
  this.audioElement.volume = 0.3;
  this.audioElement.loop = true;

// Sound propagation to child components
```

### Citation Processing Pipeline
1. **HTML Parsing**: Uses DOMParser to safely parse message content
2. **Tag Detection**: Identifies `<sup>` and `<cite>` tags with numeric content
3. **Adjacent Grouping**: Groups consecutive citations for better UX
4. **Source Matching**: Matches citation numbers to source objects
5. **Chip Conversion**: Converts tags to interactive spectrum-chip components
6. **Event Binding**: Attaches hover and click handlers for source display

## Performance Considerations

### Efficient Rendering
- **Lazy DOM Updates**: Only re-renders when messages or loading state change
- **Event Delegation**: Uses efficient event handling for multiple citations
- **Memory Management**: Proper cleanup of audio resources and event listeners

### Citation Overlay Positioning
- **Viewport Awareness**: Calculates optimal overlay position to prevent clipping
- **Grid Layout**: Uses CSS Grid for grouped citation displays
- **Mobile Adaptation**: Switches to slide-up cards on mobile devices

### Auto-Scroll Optimization
```typescript
// Optimized scroll behavior
componentDidUpdate() {
  const currentMessageCount = this.messageArray.length;
  const currentLoadingState = this.loading;
  
  // Only scroll when content actually changes
  if (currentMessageCount !== this.previousMessageCount || 
      currentLoadingState !== this.previousLoadingState) {
    setTimeout(() => this.scrollToLatest(), 50);
  }
  
  this.previousMessageCount = currentMessageCount;
  this.previousLoadingState = currentLoadingState;
}
```
