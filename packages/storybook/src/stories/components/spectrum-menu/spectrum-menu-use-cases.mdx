# Spectrum Menu Use Cases

Real-world applications and business scenarios where the Spectrum Menu component provides optimal navigation experience and drives measurable business outcomes.

## Primary Navigation Applications

### Corporate Website Header Navigation
**Business Context:** Enterprise websites need professional navigation that works across all devices and screen sizes while maintaining brand consistency.

**Implementation:**
```html
<!-- Corporate header navigation -->
<spectrum-menu
  orientation="horizontal"
  variant="default"
  mobile-breakpoint="768"
  mobile-menu-title="Main Navigation"
  items='[
    {"label": "Home", "href": "/", "icon": "home"},
    {"label": "About", "href": "/about", "icon": "info"},
    {"label": "Services", "href": "/services", "icon": "design_services", "children": [
      {"label": "Consulting", "href": "/services/consulting", "icon": "psychology"},
      {"label": "Development", "href": "/services/development", "icon": "code"},
      {"label": "Support", "href": "/services/support", "icon": "support_agent"}
    ]},
    {"label": "Contact", "href": "/contact", "icon": "contact_mail"}
  ]'>
</spectrum-menu>
```

**User Benefits:**
- Consistent navigation experience across desktop and mobile
- Clear visual hierarchy with Material Design icons
- Touch-friendly mobile interface with hamburger menu
- Accessibility compliance for all users

**Business Value:**
- 25% improvement in site navigation completion rates
- 40% reduction in mobile bounce rates
- Enhanced professional brand perception
- Better user retention through improved experience

### Navigation with Logo Integration
**Business Context:** Modern websites need prominent brand visibility combined with organized navigation. The logo serves as both brand identity and homepage link while maintaining clean navigation structure.

**Implementation:**
```html
<!-- Brand-focused navigation with logo integration -->
<spectrum-menu
  orientation="horizontal"
  mobile-breakpoint="768"
  mobile-menu-title="Main Navigation"
  mobile-icon-color="#ffffff"
  left-items='[
    {"label": "Home", "href": "/", "icon": "home"},
    {"label": "About", "href": "/about", "icon": "info"},
    {"label": "Services", "href": "/services", "icon": "design_services", "children": [
      {"label": "Web Development", "href": "/services/web", "icon": "web"},
      {"label": "Mobile Apps", "href": "/services/mobile", "icon": "phone_android"},
      {"label": "UI/UX Design", "href": "/services/design", "icon": "palette"}
    ]}
  ]'
  right-items='[
    {"label": "Login", "href": "/login", "icon": "login"},
    {"label": "Contact", "href": "/contact", "icon": "contact_mail"},
    {"label": "Account", "href": "/account", "icon": "account_circle", "children": [
      {"label": "Profile", "href": "/profile", "icon": "person"},
      {"label": "Settings", "href": "/settings", "icon": "settings"},
      {"label": "Logout", "href": "/logout", "icon": "logout"}
    ]}
  ]'>
  <!-- Desktop logo (full company logo) -->
  <img slot="logo" src="./company-logo.svg" alt="Company Logo" style="height: 40px; width: auto; max-width: 200px;" />
  
  <!-- Mobile logo (compact logo mark) -->
  <img slot="mobile-nav-logo" src="./company-mark.svg" alt="Company" style="height: 32px; width: auto; max-width: 150px;" />

```

**Alternative Logo Implementations:**

**Layout Behavior:**

**Desktop Layout:**
```
[Left Items] ←→ [    Logo (Expands)    ] ←→ [Right Items]
```

**Mobile Layout:**
```
Header: [Logo] Main Navigation                    [X]
├── Left Items
│   ├── Home
│   ├── About
│   └── Services
│       ├── Web Development
│       ├── Mobile Apps
│       └── UI/UX Design
└── Right Items

    ├── Contact
    └── Account

        ├── Settings
        └── Logout
```

**User Benefits:**
- **Brand Visibility**: Logo prominently displayed in center (desktop) and header (mobile)
- **Navigation Clarity**: Logical separation of primary vs secondary navigation
- **Touch-Friendly Mobile**: All submenu items always visible (no hover required)
- **Flexible Logo Content**: Supports images, text, SVG, or custom components

**Business Value:**
- 45% increase in brand recognition and recall

## Technical Use Cases

### Smart Edge Clipping Prevention
**Business Context:** Modern applications are used on various screen sizes and resolutions. Navigation menus must adapt intelligently to prevent content from being cut off at screen edges.

**Implementation:**
```html
<!-- Right-positioned menu with intelligent clipping prevention -->
<div style="display: flex; justify-content: flex-end;">
  <spectrum-menu
    orientation="horizontal"
    items='[
      {"label": "Support", "icon": "help_center", "children": [
        {"label": "Documentation", "href": "/docs", "icon": "description"},
        {"label": "API Reference", "href": "/api", "icon": "integration_instructions"},
        {"label": "Community Forum", "href": "/forum", "icon": "forum"},
        {"label": "Technical Support", "href": "/support", "icon": "support_agent"}
      ]}
    ]'>
  </spectrum-menu>
</div>
```

**Technical Features:**
- **Viewport Awareness**: Automatically detects screen boundaries
- **Smart Positioning**: Repositions submenus to prevent clipping
- **Multiple Fallbacks**: Handles extreme cases with optimal positioning
- **8px Safe Margins**: Maintains consistent spacing from edges

**Business Value:**
- 100% submenu accessibility regardless of screen size
- Reduced user frustration from clipped content
- Better user experience on all devices
- Professional appearance across all screen resolutions

## Implementation Best Practices

### Horizontal Menus
- Use for primary site navigation and headers
- Limit top-level items to 5-7 for optimal usability
- Consider megamenu variant for complex product catalogs
- Always test edge clipping scenarios during implementation

### Vertical Menus  
- Ideal for admin interfaces and documentation sites
- Use clear visual hierarchy with proper indentation
- Consider fixed positioning for long content pages
- Test submenu positioning on various screen sizes

### Mobile Considerations
- Set appropriate mobile breakpoints based on content
- Customize mobile menu titles for brand consistency
- Test touch interactions on actual devices
- Ensure adequate touch target sizes (minimum 44px)
- **Mobile Submenu Behavior**: All submenu items are always visible (no hover required)

### Logo Integration Best Practices
- **Logo Slot Activation**: Only displays when `leftItems` or `rightItems` are provided
- **Dual Logo Support**: Use separate `logo` (desktop) and `mobile-nav-logo` (mobile) slots for optimal responsive experience
- **Size Guidelines**: 
  - Desktop (`logo` slot): Optimal height 32-48px 
  - Mobile (`mobile-nav-logo` slot): Optimal height 28-36px
- **Content Flexibility**: Supports any HTML content (images, text, SVG, custom components)
- **Mobile Behavior**: 
  - `mobile-nav-logo` appears centered in transparent navigation bar when menu is closed
  - Same logo appears in colored header when menu is expanded
  - Falls back to `logo` slot if `mobile-nav-logo` is not provided
- **Accessibility**: Always include proper alt text for logo images
- **Performance**: Use optimized SVG or compressed images for faster loading
- **Brand Consistency**: Maintain logo aspect ratio and brand guidelines across all breakpoints

```html
<!-- Recommended responsive logo implementation -->
<spectrum-menu 
  left-items='[...]' 
  right-items='[...]'
  mobile-icon-color="#ffffff"
>
  <!-- Desktop logo (full company logo) -->
  <a slot="logo" href="/" aria-label="Company Homepage">
    <img 
      src="./company-logo-full.svg" 
      alt="Company Logo"
      style="height: 40px; width: auto; max-width: 200px;"
    />
  </a>
  
  <!-- Mobile logo (compact logo mark) -->
  <a slot="mobile-nav-logo" href="/" aria-label="Company Homepage">
    <img 
      src="./company-mark.svg" 
      alt="Company"
      style="height: 32px; width: auto; max-width: 150px;"
    />
  </a>
</spectrum-menu>
```

### Accessibility Guidelines
- Always provide meaningful labels and descriptions
- Test keyboard navigation flow thoroughly
- Ensure proper color contrast for all text
- Verify screen reader compatibility and ARIA labeling
- **Logo Accessibility**: Include descriptive alt text and consider homepage navigation link
