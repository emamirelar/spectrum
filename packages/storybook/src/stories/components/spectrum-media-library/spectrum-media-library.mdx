# Media Library Component

A comprehensive media library component that displays images and videos in a scrollable, responsive grid with an integrated lightbox viewer.

## Overview

The `spectrum-media-library` component provides a complete solution for displaying and managing media content including images and videos from various sources. It features automatic thumbnail generation for videos, a full-screen lightbox viewer with navigation, and comprehensive accessibility support.

## Key Features

- **Multi-Media Support**: Display images and videos (YouTube, Vimeo, direct links)
- **Auto-Thumbnail Extraction**: Automatic thumbnail generation for YouTube videos
- **Interactive Lightbox**: Full-screen viewer with keyboard and mouse navigation
- **Configurable Layouts**: Horizontal or vertical scrolling with customizable sizes
- **Fully Accessible**: WCAG 2.1 AA compliant with complete keyboard support
- **Touch Optimized**: Native support for mobile touch gestures
- **Event System**: Comprehensive events for tracking user interactions
- **Framework Agnostic**: Works with vanilla JS, React, Vue, Angular, and more

## API Reference

### MediaItem Interface

~~~typescript
interface MediaItem {
  id: string;                    // Unique identifier
  type: 'image' | 'video';       // Type of media
  url: string;                   // Source URL
  thumbnailUrl?: string;         // Optional custom thumbnail
  altText: string;               // Accessibility description
  caption?: string;              // Optional caption for lightbox
  platform?: 'youtube' | 'vimeo' | 'direct';  // Video platform (auto-detected)
}
~~~

### MediaActionPayload Interface

~~~typescript
interface MediaActionPayload {
  action: 'view' | 'close' | 'navigate' | 'error';
  mediaItem?: MediaItem;
  index?: number;
  errorMessage?: string;
}
~~~

### Events

| Event | Detail Type | Description |
|-------|-------------|-------------|
| `mediaAction` | `MediaActionPayload` | Emitted when media is viewed, closed, or navigated |

### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `closeLightbox()` | `Promise<void>` | Close the lightbox programmatically |
| `navigatePrevious()` | `Promise<void>` | Navigate to previous media item |
| `navigateNext()` | `Promise<void>` | Navigate to next media item |

## Video Platform Support

### YouTube

The component automatically detects YouTube URLs and extracts high-quality thumbnails.

**Supported URL formats:**
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`

**Features:**
- Automatic thumbnail extraction
- Embeddable player with autoplay
- Full player controls

### Vimeo

Vimeo videos are supported with automatic player embedding.

**URL format:** `https://vimeo.com/VIDEO_ID`

**Note:** Vimeo thumbnail extraction requires API integration. The component provides a placeholder icon.

### Direct Video Files

Direct video files (`.mp4`, `.webm`, `.ogg`) are supported with HTML5 video player.

## Best Practices

### 1. Always Provide Alt Text

~~~javascript
{
  id: 'img1',
  type: 'image',
  url: '/image.jpg',
  altText: 'Clear, descriptive text for accessibility',  // ✅ Required
  caption: 'Optional visual caption'
}
~~~

### 2. Optimize Images

- Use compressed images for better performance
- Consider using WebP format with fallbacks
- Provide appropriate dimensions for your use case

### 3. Choose Appropriate Thumbnail Sizes

- **Small (100px)**: For compact displays or many items
- **Medium (150px)**: Default, works well for most cases
- **Large (200px)**: For feature galleries or fewer items
- **Custom**: Match your specific layout requirements

### 4. Handle Events

~~~javascript
library.addEventListener('mediaAction', (event) => {
  const { action, mediaItem } = event.detail;
  
  if (action === 'error') {
    // Handle errors gracefully
    console.error('Media error:', event.detail.errorMessage);
  }
});
~~~

### 5. Test Responsively

Always test your media library on different screen sizes and devices to ensure optimal user experience.

## Performance Considerations

- **Lazy Loading**: Images load only when visible in viewport
- **Efficient Scrolling**: CSS-based overflow for smooth performance
- **GPU Acceleration**: Transform-based animations for better performance
- **Cleanup**: Automatic cleanup of event listeners and resources

## Framework Integration

### Vanilla JavaScript

~~~javascript
const library = document.querySelector('spectrum-media-library');
library.mediaItems = [...];
library.addEventListener('mediaAction', handler);
~~~

### React

~~~jsx
import { SpectrumMediaLibrary } from '@unops-itg-npm/cpit-spectrum-react';

function Gallery() {
  const mediaItems = [...];
  
  return (
    <SpectrumMediaLibrary
      mediaItems={mediaItems}
      width="100%"
      height="400px"
      onMediaAction={(e) => console.log(e.detail)}
    />
  );
}
~~~

### Vue

~~~vue
<template>
  <spectrum-media-library
    :media-items="mediaItems"
    width="100%"
    height="400px"
    @mediaAction="handleAction"
  />
</template>

<script>
export default {
  data() {
    return {
      mediaItems: [...]
    };
  }
};
</script>
~~~

### Angular

~~~typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-gallery',
  template: `
    <spectrum-media-library
      [mediaItems]="mediaItems"
      width="100%"
      height="400px"
      (mediaAction)="handleAction($event)"
    ></spectrum-media-library>
  `
})
export class GalleryComponent {
  mediaItems = [...];
}
~~~
