## 🏗️ Architecture Integration

### SpectrumApplicationLayout Integration Pattern
The spectrum-application-layout component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() showHeaderAppId?: boolean;
  @Prop() showHeaderMiddle?: boolean;
  @Prop() showHeaderUtility?: boolean;

  render() {
    return (
      <div class="example-component">
        <spectrum-application-layout
          showHeaderAppId={this.showHeaderAppId}
          showHeaderMiddle={this.showHeaderMiddle}
        >
          Component Content
        </spectrum-application-layout>
      </div>
    );
  }
}
```
