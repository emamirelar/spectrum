## 🏗️ Architecture Integration

### SpectrumToast Integration Pattern
The spectrum-toast component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() debug?: boolean;
  @Prop() variant?: 'primary' | 'secondary' | 'success' | 'warning' | 'danger' | 'ghost';
  @Prop() position?: 'top' | 'bottom' | 'left' | 'right' | 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right';

  render() {
    return (
      <div class="example-component">
        <spectrum-toast
          debug={this.debug}
          variant={this.variant}
        >
          Component Content
        </spectrum-toast>
      </div>
    );
  }
}
```
