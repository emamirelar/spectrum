## Direct Dependencies

### spectrum-chip
- **Relationship**: Direct internal dependency
- **Usage**: The chip variant uses `spectrum-chip` as the trigger element
- **Why**: Provides consistent chip styling and interaction patterns
- **Props Passed**: `variant`, `outline`, `label`, `leadingIcon`, `sound`, `haptic`, `disabled`

```typescript
// Internal chip usage in accordion
<spectrum-chip 
  variant={this.chipVariant}
  outline={this.outline}
  label={this.label}
  sound={this.sound}
  haptic={this.haptic}
  leadingIcon={this.isExpanded ? this.expandedIcon : this.collapsedIcon}
  onClick={this.handleChipToggle}
  selected={this.isExpanded}
  disabled={this.disabled}
/>
```

## Dependent Components

### spectrum-conversation-panel
- **Relationship**: Uses accordion for expandable content sections
- **Usage**: Integrates accordion to organize conversation content
- **Integration Pattern**: Embeds accordion with custom content
- **Event Handling**: Listens to `accordionToggle` events for state management

```typescript
// Usage in conversation panel
<spectrum-accordion
  variant="chip"
  label="Additional Resources"
  @accordionToggle=${this.handleAccordionToggle}
>
  <div slot>
    <!-- Custom conversation content -->
  </div>
</spectrum-accordion>
```

## Content Integration Patterns

### Slot-based Content
The accordion supports flexible content through slots:

```html

  <div slot="section-custom1">
    <spectrum-button variant="primary">Action</spectrum-button>

  </div>
  
  <div slot="section-custom2">
    <spectrum-image-gallery></spectrum-image-gallery>
  </div>

<!-- Chip variant with any content -->
<spectrum-accordion variant="chip" label="Tools">
  <spectrum-button>Tool 1</spectrum-button>
  <spectrum-button>Tool 2</spectrum-button>
  <spectrum-chip label="Option 3"></spectrum-chip>
</spectrum-accordion>
```

Components communicate through well-defined events:

```typescript
// Accordion emits events

  accordionId: string,

  expandedSections?: string[]
});

// Parent components listen
@Listen('accordionToggle')
handleAccordionToggle(event: CustomEvent) {
  const { expanded, accordionId, sectionId } = event.detail;

}
```

## Integration Best Practices

### 1. Event Propagation
Always handle accordion events at the appropriate level:

```typescript
// ✅ Good: Handle at parent level
<parent-component @accordionToggle=${this.handleToggle}>
  <spectrum-accordion variant="chip">
    <!-- Content -->
  </spectrum-accordion>
</parent-component>

// ❌ Avoid: Stopping event propagation unnecessarily
handleToggle(event: CustomEvent) {
  event.stopPropagation(); // Only if required
}
```

### 2. Content Organization
Structure content logically within accordions:

```html
<!-- ✅ Good: Logical content grouping -->
<spectrum-accordion variant="standard" sections='[
  {"id": "overview", "title": "Overview"},
  {"id": "details", "title": "Details"},
  {"id": "actions", "title": "Actions"}
]'>
  <div slot="section-actions">
    <spectrum-button variant="primary">Primary Action</spectrum-button>
    <spectrum-button variant="secondary">Secondary Action</spectrum-button>
  </div>
</spectrum-accordion>
```

### 3. State Management
Coordinate accordion state with parent components:

```typescript
// ✅ Good: Sync state between components
@State() accordionExpanded: boolean = false;

handleAccordionToggle = (event: CustomEvent) => {
  this.accordionExpanded = event.detail.expanded;
  // Update other related UI state
  this.updateRelatedComponents();
}
```

## Performance Considerations

### 1. Lazy Content Loading
For complex content, consider lazy loading:

```typescript
// Only render content when expanded
{this.isExpanded && (
  <div slot="section-heavy-content">
    <expensive-component></expensive-component>
  </div>
)}
```

### 2. Event Optimization
Debounce rapid accordion toggles if needed:

```typescript
private toggleDebounce: any;

handleToggle = (event: CustomEvent) => {
  clearTimeout(this.toggleDebounce);
  this.toggleDebounce = setTimeout(() => {
    this.processToggle(event.detail);
  }, 100);
}
```

## Migration Patterns

### From Basic Accordions
When migrating from simpler accordion implementations:

```typescript
// Before: Basic accordion
<basic-accordion title="Section">
  Content
</basic-accordion>

// After: Spectrum accordion
<spectrum-accordion 
  variant="standard"
  sections='[{"id": "section", "title": "Section", "content": "Content"}]'>
</spectrum-accordion>
```

### Integration with Existing Systems
When integrating with existing component systems:

```typescript
// Wrapper component for legacy integration
@Component({

export class LegacyAccordionWrapper {
```
