# Score Card Use Cases

Real-world applications and business scenarios where Score Card (KPI) components provide optimal user experience and drive measurable business outcomes.

## Business Applications

### Executive Dashboard Overview
**Business Context:** Executives and managers need quick visibility into key business metrics without diving into detailed reports. Score cards provide at-a-glance KPI monitoring that enables rapid decision-making and issue identification.

**Implementation:**
```html
<!-- Executive KPI dashboard -->
<div class="kpi-grid">
  <spectrum-score-card
    label="Total Revenue"
    value="$2.5M"
    value-prefix="$"
    variant="primary"
    icon="attach_money"
    trend='{
      "value": 12.5,
      "direction": "up",
      "isPositive": true,
      "label": "vs last month"
    }'
    subtitle="Q4 2024"
    @scoreCardClick=${drillToRevenue}
  />
  
  <spectrum-score-card
    label="Active Customers"
    value="1,234"
    variant="success"
    icon="people"
    trend='{
      "value": 8.2,
      "direction": "up",
      "isPositive": true
    }'
    @scoreCardClick=${drillToCustomers}
  />
  
  <spectrum-score-card
    label="Churn Rate"
    value="2.1"
    value-suffix="%"
    variant="warning"
    icon="trending_down"
    trend='{
      "value": 0.5,
      "direction": "up",
      "isPositive": false,
      "label": "needs attention"
    }'
    @scoreCardClick=${drillToChurn}
  />
</div>
```

**User Benefits:**
- Instant visibility into critical business metrics
- Visual trend indicators for quick pattern recognition
- Click to drill-down for detailed analysis
- Color-coded status for priority identification

**Business Value:**
- 60% faster executive decision-making
- 45% improvement in issue detection time
- Enhanced strategic planning with real-time insights
- Better resource allocation based on KPIs

## Dashboard Integration Patterns

### Overview Dashboard
**Use Case:** High-level KPI overview with drill-down

```json
{
  "layout": "grid-3col",
  "widgets": {
    "revenue": {
      "component": "score-card",
      "drillDown": {
        "action": "dashboard-nav",
        "targetDashboardId": "revenueDetails"
      }
    }
  }
}
```

**Benefits:**
- Executive summary view
- Click to explore details
- Context preservation during navigation

### Comparison Dashboard
**Use Case:** Side-by-side metric comparisons

```json
{
  "widgets": {
    "thisMonth": { "component": "score-card", "label": "This Month" },
    "lastMonth": { "component": "score-card", "label": "Last Month" }
  }
}
```

**Benefits:**
- Period-over-period comparisons
- Visual trend identification
- Performance benchmarking

## Best Practices

### Visual Hierarchy
- **Primary Metrics**: Use larger values, primary variants
- **Supporting Metrics**: Use smaller cards, neutral variants
- **Alert Metrics**: Use warning/danger variants, prominent placement

### Trend Communication
- **Positive Trends**: Green, up arrow, positive language
- **Negative Trends**: Red, down arrow, attention language
- **Neutral Trends**: Gray, neutral indicators

### Grid Layouts
- **3-Column**: Ideal for 3-6 primary KPIs
- **4-Column**: Best for 8-12 supporting metrics
- **Responsive**: Stack on mobile, grid on desktop
