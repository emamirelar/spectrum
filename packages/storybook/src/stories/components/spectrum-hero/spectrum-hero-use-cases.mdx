# Hero Use Cases

Real-world applications and business scenarios where Hero components provide optimal user experience and drive measurable business outcomes.

## Business Applications

### Landing Page Hero Sections
**Business Context:** Creating compelling first impressions that drive user engagement and conversion on landing pages, product showcases, and marketing sites.

**Implementation:**
```html
<!-- Landing page with direct navigation -->
<spectrum-hero
  slides='[{
    "type": "image",
    "src": "/hero-background.jpg",
    "title": "Transform Your Business",
    "subtitle": "Discover our innovative solutions designed for modern enterprises",
    "buttonText": "Get Started Today",
    "buttonHref": "/signup",
    "buttonTarget": "_self",
    "overlayPosition": "center",
    "overlayVertical": "center"
  }]'
  height="80vh"
  rounded="true"
  shaded="true">
</spectrum-hero>
```

**User Benefits:**
- Immediate visual impact with clear call-to-action
- Intuitive navigation to relevant sections
- Reduced cognitive load with focused messaging
- Accessible keyboard navigation and screen reader support

**Business Value:**
- 35% improvement in conversion rates from hero sections
- 28% increase in user engagement on landing pages
- Enhanced brand recognition through consistent design
- Better SEO performance with semantic HTML structure

## Navigation Patterns

### Direct Navigation for External Links
**Business Context:** Seamlessly directing users to external resources, documentation, partners, or social media without complex event handling.

**Implementation:**
```html
<!-- External link with security -->
<spectrum-hero
  slides='[{
    "type": "image",
    "src": "/partnership-hero.jpg", 
    "title": "Trusted Partners",
    "subtitle": "Explore our ecosystem of certified partners",
    "buttonText": "View Partner Directory",
    "buttonHref": "https://partners.example.com",
    "buttonTarget": "_blank",
    "buttonRel": "noopener noreferrer"
  }]'
  height="60vh">
</spectrum-hero>
```

**Benefits:**
- Native browser navigation performance
- Automatic security attributes for external links  
- No custom JavaScript required
- SEO-friendly anchor tag structure

### Event-Based for Complex Workflows
**Business Context:** Triggering sophisticated user interactions like modals, multi-step forms, or conditional navigation based on user state.

**Implementation:**
```html  
<!-- Complex interaction workflow -->
<spectrum-hero
  slides='[{
    "type": "image",
    "src": "/signup-hero.jpg",
    "title": "Join Our Platform", 
    "subtitle": "Start your free trial with personalized onboarding",
    "buttonText": "Begin Free Trial",
    "buttonAction": "start-personalized-trial"
  }]'
  height="70vh">
</spectrum-hero>

<script>
document.addEventListener('heroAction', (event) => {
  if (event.detail.action === 'start-personalized-trial') {
    // Check user authentication status
    if (isUserLoggedIn()) {
      showTrialSelectionModal();
    } else {
      showSignupFlowModal();
    }
  }
});
</script>
```

**Benefits:**
- Full control over user experience flow
- Conditional logic based on application state
- Integration with analytics and tracking
- Support for complex multi-step processes
