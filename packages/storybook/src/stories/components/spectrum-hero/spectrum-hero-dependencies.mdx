## 🏗️ Architecture Integration

### SpectrumHero Integration Pattern
The spectrum-hero component follows a composed integration pattern with multiple internal dependencies:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() slides?: string;
  @Prop() autoplay?: number;
  @Prop() animationDuration?: number;

  render() {
    return (
      <div class="example-component">
        <spectrum-hero
          slides={this.slides}
          autoplay={this.autoplay}
        >
          Component Content
        </spectrum-hero>
      </div>
    );
  }
}
```
