# 🔗 Spectrum Hero Dependencies

This document shows the dependency relationships for the spectrum-hero component and how it integrates with other components in the Spectrum system.

---

## 📋 Component Usage Overview

**spectrum-hero** is a Level 2 composed component that depends on spectrum-button for call-to-action functionality. It provides hero section functionality for landing pages, feature highlights, and content showcase applications.

### Dependencies
- **spectrum-button** (for call-to-action buttons)

### Components Using spectrum-hero
- **Direct Usage**: Landing pages, feature highlights, and content showcase applications

## 🏗️ Architecture Integration

### Button Integration Pattern
```html
<!-- spectrum-hero uses spectrum-button internally -->
<spectrum-hero 
  primaryButtonText="Get Started"
  primaryButtonAction="get-started"
  primaryButtonVariant="primary"
  secondaryButtonText="Learn More"
  secondaryButtonAction="learn-more"
  secondaryButtonVariant="secondary">
</spectrum-hero>
```

### Event Flow
1. Hero renders internal spectrum-button components
2. Button properties pass through directly from hero to button
3. Button handles all visual states and animations
4. Hero emits unified `heroAction` events with button context
5. Parent components receive consolidated hero events

---

## 🚀 Integration Benefits

### Button Reusability
- Consistent button behavior across hero implementations
- Automatic button styling inheritance
- Unified event handling pattern
- Reduced component complexity

### Maintainability
- Button updates automatically propagate to hero
- Single source of truth for button behavior
- Consistent accessibility patterns
- Easier testing and debugging
