# 🎯 SpectrumCard Use Cases

## Primary Use Cases

### 1. Content Display Cards
**Purpose**: Display articles, blog posts, news items, and other content with preview information.

```html
<spectrum-card
  card-title="Breaking News: Tech Innovation"
  card-subtitle="Technology • 2 hours ago"
  card-content="Discover the latest breakthrough in artificial intelligence that's revolutionizing how we work."
  image-url="news-image.jpg"
  clickable
  action="read-article">
</spectrum-card>
```

**Key Features**: Title, subtitle, content preview, featured image, click navigation

### 2. Product Catalog Cards
**Purpose**: E-commerce product displays with images, pricing, ratings, and purchase actions.

```html
<spectrum-card
  card-title="Wireless Bluetooth Headphones"
  card-subtitle="Premium Audio Collection"
  card-content="High-quality sound with noise cancellation and 30-hour battery life."
  image-url="product-image.jpg"
  variant="elevated"
  show-header-actions
  show-footer-actions>
  
  <div slot="header-actions">
    <span style="font-weight: bold; color: var(--spectrum-sys-color-primary);">$299.99</span>
    <spectrum-badge text="Sale" variant="danger"></spectrum-badge>
  </div>
  
  <spectrum-button slot="footer-actions" variant="secondary" button-text="Add to Cart"></spectrum-button>
  <spectrum-button slot="footer-actions" variant="primary" button-text="Buy Now"></spectrum-button>
</spectrum-card>
```

**Key Features**: Product images, pricing display, action buttons, promotional badges

**Key Features**: Form organization, clear actions, sectioned content

## Layout Patterns

### Grid Layouts
Use cards in responsive grid systems for consistent spacing and alignment:

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 1.5rem;
  padding: 1rem;
}
```

### List Layouts
Stack cards vertically for content feeds and detailed listings:

```css
.card-list {
  display: flex;
  flex-direction: column;
  gap: 1rem;
  max-width: 600px;
}
```

### Masonry Layouts
Use varying card heights for dynamic, Pinterest-style layouts:

```css
.card-masonry {
  column-count: auto;
  column-width: 300px;
  column-gap: 1.5rem;
}
```

## Integration Examples

### With Other Spectrum Components
- **spectrum-rail**: Navigation cards in sidebar menus
- **spectrum-dialog**: Card content within modal dialogs
- **spectrum-accordion**: Expandable card sections
- **spectrum-conversation-panel**: Message cards in chat interfaces

### With External Libraries
- **Search/Filter**: Cards as search result items
- **Pagination**: Cards in paginated content lists
- **Drag & Drop**: Draggable cards for organization interfaces
- **Virtual Scrolling**: Cards in large dataset presentations

## Accessibility Considerations

### Keyboard Navigation
- Clickable cards are keyboard accessible with proper focus management
- Action buttons within cards maintain tab order
- Screen readers announce card structure and interactive elements

### Screen Reader Support
- Proper heading hierarchy with card titles
- Descriptive alt text for card images
- Action buttons with clear labels and purposes

### Visual Accessibility
- High contrast mode support with enhanced borders
- Reduced motion support for animations and transitions
- Consistent color usage following design system guidelines

## Performance Best Practices

### Image Optimization
- Use appropriate image sizes for card media
- Implement lazy loading for cards with images
- Provide fallbacks for missing or failed image loads

### Content Management
- Keep card content concise and scannable
- Use progressive disclosure for detailed information
- Implement virtual scrolling for large card collections

### Event Handling
- Use event delegation for card collections
- Debounce rapid user interactions
- Provide visual feedback for user actions
