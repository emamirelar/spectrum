# 🔗 SpectrumTheme Dependencies

This document shows the dependency relationships for the spectrum-theme component and how it integrates with other components in the Spectrum system.

---

## 📋 Component Usage Overview

**spectrum-theme** is a Level 0 foundation component that provides Material Design 3 color system, theming, and FOUC prevention for all Spectrum applications.

### Dependencies
- **@material/material-color-utilities**: Material Design 3 color generation algorithms
- **FontLoader utility**: Automatic font loading and FOUC prevention system

### Components Using spectrum-theme
- **All Components**: Used by every component in the Spectrum system (through CSS custom properties)
- **spectrum-wallpaper**: Coordinates via events for color extraction and theme synchronization

### Coordination Patterns
- **Event-based coordination** with spectrum-wallpaper for dynamic color theming
- **Global CSS custom properties** provide theme values to all components
- **Singleton font loading** prevents duplicate font initialization across components

## 🏗️ Architecture Integration

### SpectrumTheme Integration Pattern
The spectrum-theme component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() color?: string;
  @Prop() dark?: boolean;
  @Prop() showSwatches?: boolean;

  render() {
    return (
      <div class="example-component">
        <spectrum-theme
          color={this.color}
          dark={this.dark}
        >
          Component Content
        </spectrum-theme>
      </div>
    );
  }
}
```

## 🔄 Event Flow

### Theme Lifecycle Events
- **themeready**: Emitted when theme is fully loaded (fonts + colors)
- **themefontsloaded**: Font loading completed successfully  
- **themefontsfailed**: Font loading failed, using fallbacks
- **themewallpaperready**: Wallpaper coordination completed

### Global Font Events  
- **fontsloaded**: Global font loading success (all components)
- **fontsfailed**: Global font loading failure

### Wallpaper Coordination Events
- **wallpaper-colors-ready**: Received when wallpaper color extraction completes
- **wallpaper-colors-failed**: Received when wallpaper color extraction fails

### Event Coordination Pattern
```
spectrum-theme ←→ spectrum-wallpaper
     ↓                    ↓
  Font Loading      Color Extraction
     ↓                    ↓
    Theme Ready Event (Combined)
     ↓
  CSS Classes Applied
     ↓
  Content Visibility Enabled
```
