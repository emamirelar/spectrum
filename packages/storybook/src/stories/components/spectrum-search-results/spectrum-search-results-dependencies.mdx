## 🏗️ Architecture Integration

### SpectrumSearchResults Integration Pattern
The spectrum-search-results component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() data?: SearchResultsData | string;
  @Prop() resultsPerPage?: number;
  @Prop() showThumbnails?: boolean;

  render() {
    return (
      <div class="example-component">
        <spectrum-search-results
          data={this.data}
          resultsPerPage={this.resultsPerPage}
        >
          Component Content
        </spectrum-search-results>
      </div>
    );
  }
}
```
