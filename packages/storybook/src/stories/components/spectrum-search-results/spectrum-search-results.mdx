# Spectrum Search Results

The `spectrum-search-results` component is a comprehensive solution for displaying search results with built-in pagination support. It handles JSON data structures and provides rich interaction capabilities through events.

## Features

- **Dual Navigation Modes**: Choose between event-based navigation (SPA) or direct HTML links (traditional)
- **Transparent Background**: Seamless integration with any design system - no default background
- **Flexible Data Structure**: Accepts JSON data with results and pagination info
- **Rich Result Display**: Shows titles, descriptions, URLs, thumbnails, and metadata
- **Pagination Support**: Built-in pagination with customizable controls
- **Loading States**: Handles loading and empty states gracefully
- **Accessibility**: Full keyboard navigation and screen reader support
- **Responsive Design**: Adapts to mobile and desktop layouts
- **Event-driven**: Emits events for result clicks and pagination actions

## Data Structure

The component expects a data structure that includes both results and pagination information:

```typescript
interface SearchResultsData {
  results: SearchResult[];
  pagination: PaginationOptions;
  query?: string;
  executionTime?: number;
}

interface SearchResult {
  id: string;
  title: string;
  description?: string;
  url?: string;
  metadata?: Record<string, any>;
  thumbnail?: string;
  timestamp?: string;
  score?: number;
}

interface PaginationOptions {
  currentPage: number;
  totalPages: number;
  totalResults: number;
  resultsPerPage: number;
  showFirstLast?: boolean;
  showPrevNext?: boolean;
  maxPageButtons?: number;
}
```

## Events

The component emits two main events:

### resultAction
Emitted when a user interacts with a search result.

```typescript
interface SearchResultActionPayload {
  action: 'click' | 'navigate' | 'select';
  result: SearchResult;
  index: number;
}
```

### paginationAction
Emitted when pagination controls are used.

```typescript
interface PaginationActionPayload {
  action: 'page-change' | 'next' | 'previous' | 'first' | 'last';
  currentPage: number;
  targetPage: number;
  totalPages: number;
}
```

## Example Usage

### Basic Setup

```javascript
// Listen to events
document.querySelector('spectrum-search-results')
  .addEventListener('resultAction', (e) => {
    console.log('Result clicked:', e.detail.result.title);
    // Handle result click, e.g., navigate to URL
  });

document.querySelector('spectrum-search-results')
  .addEventListener('paginationAction', (e) => {
    console.log('Page changed to:', e.detail.targetPage);
    // Fetch new results for the target page
  });

// Update data
const searchResults = {
  results: [...], // Your search results
  pagination: {
    currentPage: 1,
    totalPages: 10,
    totalResults: 100,
    resultsPerPage: 10
  }
};

document.querySelector('spectrum-search-results').data = searchResults;
```

### Navigation Modes

The component supports two navigation modes controlled by the `directNavigation` property:

#### Event-Based Navigation (Default)

```javascript
// Event-based navigation (default)
const component = document.querySelector('spectrum-search-results');
component.directNavigation = false; // Default

component.addEventListener('resultAction', (e) => {
  const { result, action } = e.detail;
  
  // Handle navigation with your router
  if (action === 'click') {
    // React Router example
    router.push(result.url);
    
    // Vue Router example
    // this.$router.push(result.url);
    
    // Analytics tracking
    analytics.track('search_result_clicked', {
      result_id: result.id,
      result_title: result.title,
      query: searchQuery
    });
  }
});
```

#### Direct Link Navigation

```javascript
// Direct HTML link navigation
const component = document.querySelector('spectrum-search-results');
component.directNavigation = true;

// Results become actual <a> tags that navigate directly
// No event handling needed - browser handles navigation
// Perfect for traditional multi-page applications
```

```html
<!-- HTML attribute approach -->
<spectrum-search-results 
  direct-navigation="true"
  .data=${searchData}>
</spectrum-search-results>

<!-- Results will render as: -->

```

### URL Synchronization

```javascript
// Enable URL sync for deep linking
const component = document.querySelector('spectrum-search-results');
component.enableUrlSync = true;
component.pageParam = 'page';     // URL will use ?page=N
component.sizeParam = 'per_page'; // URL will use ?per_page=N

// Programmatically navigate to a page
await component.navigateToPage(3);

// Get current pagination state including URL params
const state = await component.getPaginationState();
console.log('Current page:', state.currentPage);
console.log('URL params:', state.urlParams);

// Listen for pagination changes and update search results
component.addEventListener('paginationAction', async (e) => {
  const { targetPage } = e.detail;
  
  // Fetch new data for the target page
  const newData = await fetchSearchResults(query, targetPage);
  
  // Update component data (URL is already updated automatically)
  component.data = newData;
});
```

### Deep Linking Support

```html
<!-- Component will automatically read page from URL on load -->
<spectrum-search-results 
  enable-url-sync="true"
  page-param="page"
  size-param="size">
</spectrum-search-results>
```

URLs like `?page=5&size=20&other=value` will:
- Set current page to 5
- Set results per page to 20
- Preserve other query parameters
- Allow bookmarking and sharing of specific pages
