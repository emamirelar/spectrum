# Spectrum Search Results - Use Cases

The `spectrum-search-results` component is designed to handle various search result display scenarios across different types of applications.

## Search Engine Results

Display web search results with URLs, descriptions, and metadata. Perfect for building search engine interfaces or site-wide search functionality.

```html
<spectrum-search-results 
  .data=${webSearchData}
  showThumbnails="true"
  showMetadata="true">
</spectrum-search-results>
```

**Key Features:**
- URL display for navigation
- Description snippets
- Search execution time
- Pagination for large result sets

### URL Synchronization Integration

```javascript
// Complete search interface with URL synchronization
class SearchInterface {
  constructor() {
    this.searchInput = document.querySelector('spectrum-search-input');
    this.searchResults = document.querySelector('spectrum-search-results');
    this.currentQuery = '';
    
    // Enable URL sync
    this.searchResults.enableUrlSync = true;
    this.searchResults.pageParam = 'page';
    this.searchResults.sizeParam = 'size';
    
    this.setupEventListeners();
    this.initializeFromUrl();
  }
  
  setupEventListeners() {
    // Handle search submissions
    this.searchInput.addEventListener('searchSubmit', (e) => {
      this.performSearch(e.detail.query, 1);
    });
    
    // Handle pagination changes
    this.searchResults.addEventListener('paginationAction', (e) => {
      this.performSearch(this.currentQuery, e.detail.targetPage);
    });
  }
  
  async initializeFromUrl() {
    const urlParams = new URLSearchParams(window.location.search);
    const query = urlParams.get('q') || '';
    const page = parseInt(urlParams.get('page') || '1', 10);
    
    if (query) {
      this.searchInput.value = query;
      await this.performSearch(query, page);
    }
  }
  
  async performSearch(query, page = 1) {
    this.currentQuery = query;
    this.searchResults.loading = true;
    
    try {
      const results = await this.fetchResults(query, page);
      this.searchResults.data = results;
      
      // Update query parameter in URL
      const url = new URL(window.location);
      if (query) {
        url.searchParams.set('q', query);
      } else {
        url.searchParams.delete('q');
      }
      window.history.replaceState(null, '', url);
      
    } catch (error) {
      console.error('Search failed:', error);
      this.searchResults.data = { results: [], pagination: {...} };
    } finally {
      this.searchResults.loading = false;
    }
  }
}
```

## Data Transformation Examples

### From REST API

```javascript
function transformAPIResponse(apiResponse) {
  return {
    results: apiResponse.items.map(item => ({
      id: item.id,
      title: item.title,
      description: item.summary,
      url: item.href,
      thumbnail: item.image_url,
      timestamp: item.created_at,
      metadata: {
        category: item.category,
        author: item.author,
        tags: item.tags
      }
    })),
    pagination: {
      currentPage: apiResponse.page,
      totalPages: apiResponse.total_pages,
      totalResults: apiResponse.total_count,
      resultsPerPage: apiResponse.per_page
    },
    query: apiResponse.query,
    executionTime: apiResponse.duration_ms
  };
}
```

### From GraphQL

```javascript
function transformGraphQLResponse(gqlResponse) {
  const { searchResults, pageInfo } = gqlResponse.data.search;
  
  return {
    results: searchResults.edges.map(edge => ({
      id: edge.node.id,
      title: edge.node.title,
      description: edge.node.excerpt,
      url: edge.node.url,
      score: edge.score,
      metadata: edge.node.metadata
    })),
    pagination: {
      currentPage: pageInfo.currentPage,
      totalPages: pageInfo.totalPages,
      totalResults: pageInfo.totalCount,
      resultsPerPage: pageInfo.pageSize
    }
  };
}
```

## Best Practices

1. **Performance**: Use pagination for large result sets (>100 items)
2. **Accessibility**: Always provide meaningful empty state messages
3. **Loading States**: Show loading indicators during search operations
4. **Error Handling**: Handle API failures gracefully with appropriate messaging
5. **Responsive Design**: Configure appropriately for mobile vs desktop
6. **Event Handling**: Always handle result and pagination events
7. **Data Validation**: Validate data structure before passing to component
8. **Theming**: Use CSS custom properties for consistent styling
