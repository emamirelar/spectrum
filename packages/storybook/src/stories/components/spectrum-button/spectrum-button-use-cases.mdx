## 🎯 Best Practices by Use Case

### High-Stakes Actions
- Use `variant="danger"` for destructive actions
- Include confirmation dialogs for critical operations
- Add clear icons that reinforce the action meaning

### Primary User Flows
- Use `variant="primary"` for main conversion actions
- Implement `size="lg"` for important CTAs
- Position prominently in the interface hierarchy

### Secondary Actions
- Use `variant="secondary"` or `variant="outline"` 
- Maintain visual hierarchy with primary actions
- Group related secondary actions together

### Mobile Considerations
- Use `variant="fab"` for primary mobile actions
- Ensure minimum 44px touch targets
- Consider thumb-friendly positioning

### Accessibility Focus
- Always include meaningful `action` attributes
- Use appropriate `aria-label` for icon-only buttons
- Ensure sufficient color contrast in all variants
