# 🔗 Spectrum Button Dependencies

This document shows the dependency relationships for the spectrum-button component and how it integrates with other components in the Spectrum system.

---

## 📋 Component Usage Overview

**spectrum-button** is a foundational atomic component used by 7 other components in the system. It provides consistent interactive behavior, theming, and accessibility across all button implementations.

### Components Using spectrum-button

- **spectrum-rail** (main navigation)
- **spectrum-search-input** (search functionality)  
- **spectrum-rail-item** (navigation items)
- **spectrum-select** (form components)
- **spectrum-image-gallery** (image management)
- **spectrum-hero** (landing pages)
- **spectrum-conversation-panel** (AI/chat systems)

## 📦 Integration Patterns

### Button Integration Pattern
Multiple components use spectrum-button as internal trigger:
- Properties pass through directly: `variant`, `size`, `disabled`
- Button handles all visual states (hover, focus, active) and animations
- Parent wrapper becomes transparent container

### Usage Examples in Dependent Components

#### spectrum-rail
```html
<spectrum-button 
  variant="ghost" 
  icon-only 
  show-left-icon 
  left-icon="menu">
</spectrum-button>
```

#### spectrum-search-input
```html
<spectrum-button 
  variant="primary" 
  show-left-icon 
  left-icon="search" 
  button-text="Search">
</spectrum-button>
```

#### spectrum-hero
```html
<spectrum-button 
  variant="primary" 
  size="lg" 
  button-text="Get Started">
</spectrum-button>
```
