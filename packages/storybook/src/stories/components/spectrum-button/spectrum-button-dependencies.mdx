## 🏗️ Architecture Integration

### SpectrumButton Integration Pattern
The spectrum-button component follows a simple integration pattern as an atomic component:

```typescript
// Integration pattern example
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'example-component'
})
export class ExampleComponent {
  @Prop() debug?: boolean;
  @Prop() variant?: 'primary' | 'secondary' | 'success' | 'warning' | 'danger' | 'ghost' | 'outline' | 'fab';
  @Prop() size?: 'sm' | 'base' | 'lg';

  render() {
    return (
      <div class="example-component">
        <spectrum-button
          debug={this.debug}
          variant={this.variant}
        >
          Component Content
        </spectrum-button>
      </div>
    );
  }
}
```
