## ♿ Accessibility Considerations

### High Contrast Support
Ensure badges remain visible and meaningful in high contrast modes.

```html
<!-- Accessible status badges with meaningful text -->
<spectrum-badge text="✓ Approved" variant="success"></spectrum-badge>
<spectrum-badge text="⚠ Review Required" variant="warning"></spectrum-badge>
<spectrum-badge text="✗ Rejected" variant="danger"></spectrum-badge>
```

### Screen Reader Support
Use descriptive text instead of relying solely on color to convey meaning.

```html
<!-- Screen reader friendly badges -->
<spectrum-badge text="3 unread messages" variant="danger" circular></spectrum-badge>
<spectrum-badge text="Online status" variant="success" circular></spectrum-badge>
<spectrum-badge text="Draft document" variant="secondary"></spectrum-badge>
```

### Touch Targets
Ensure badges used as interactive elements meet minimum touch target sizes.

```html
<!-- Touch-friendly interactive badges -->
<spectrum-badge text="Filter" variant="primary" size="large"></spectrum-badge>
<spectrum-badge text="Sort" variant="secondary" size="large"></spectrum-badge>
```

## 💡 Best Practices by Use Case

### Notification Badges
- Use circular badges for counts and numerical indicators
- Red (danger) variant for urgent notifications
- Keep count text short (use "99+" for large numbers)
- Position consistently (typically top-right of parent element)

### Status Indicators
- Use color meaningfully (green=good, yellow=warning, red=error)
- Include descriptive text for accessibility
- Consider using dot (●) for simple on/off status
- Provide hover states with additional context

### E-commerce Badges
- Use sparingly to maintain impact
- Ensure badges don't interfere with product images
- Use appropriate variants (danger for sales, success for features)
- Consider seasonal and promotional contexts

### Mobile Considerations
- Use larger sizes for better touch accessibility
- Ensure adequate contrast on various backgrounds
- Position badges to avoid accidental activation
- Test on actual devices for optimal sizing

### Performance Considerations
- Use CSS positioning for overlay badges
- Avoid excessive DOM nesting
- Consider using CSS-only badges for static content
- Implement proper loading states for dynamic badge content
