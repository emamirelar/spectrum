# 🔗 Spectrum Badge Dependencies

## 📋 Component Usage Overview

**spectrum-badge** is a Level 1 atomic component with no internal dependencies. It provides foundational status and notification functionality and is currently used by spectrum-image-gallery for visual selection indicators.

### Dependencies
- **None** (pure atomic component)

### Components Using spectrum-badge

- **spectrum-image-gallery** (selection indicators and status badges)

## 🏗️ Architecture Integration

### Badge Integration Pattern
The badge component follows a consistent integration pattern across all dependent components:

```typescript
// Common integration pattern in dependent components
import { Component, h, Prop } from '@stencil/core';

@Component({
  tag: 'spectrum-example-component'
})
export class ExampleComponent {
  @Prop() badgeVariant?: 'primary' | 'secondary' | 'success' | 'warning' | 'danger' = 'primary';
  @Prop() badgeSize?: 'small' | 'medium' | 'large' = 'small';
  @Prop() showBadge?: boolean = false;
  @Prop() badgeText?: string = '';

  render() {
    return (
      <div class="example-component">
        <div class="content">
          {/* Component content */}
        </div>
        {this.showBadge && (
          <spectrum-badge
            variant={this.badgeVariant}
            size={this.badgeSize}
            text={this.badgeText}
            class="status-badge"
          />
        )}
      </div>
    );
  }
}
```

### Status Display Pattern
Dependent components typically use badges for status communication:

```typescript
// spectrum-image-gallery example
<div class="image-item">
  <img src={this.imageUrl} alt={this.imageAlt} />
  {this.isSelected && (
    <spectrum-badge
      variant="primary"
      text="Selected"
      size="small"
      circular={false}
      class="selection-badge"
    />
  )}
  {this.uploadStatus === 'uploading' && (
    <spectrum-badge
      variant="warning"
      text="Uploading"
      size="small"
      class="status-badge"
    />
  )}
</div>
```

### Notification Count Pattern
```typescript
// spectrum-navigation example
<nav class="navigation">
  <div class="nav-item">
    <spectrum-icon name="notifications" />
    <span>Notifications</span>
    {this.notificationCount > 0 && (
      <spectrum-badge
        variant="danger"
        text={this.notificationCount.toString()}
        size="small"
        circular={true}
        class="notification-count"
      />
    )}
  </div>
</nav>
```

## 🔧 Development Considerations

### When Modifying spectrum-badge
1. **Impact Assessment** - Changes affect spectrum-image-gallery component
2. **Visual Consistency** - Ensure changes maintain design system coherence
3. **Semantic Meaning** - Verify color variants maintain semantic clarity
4. **Accessibility Testing** - Test contrast ratios and screen reader compatibility
5. **Performance Testing** - Verify no performance regressions in badge-heavy interfaces

When using spectrum-badge in new components:

- [ ] **Size Selection** - Choose size that fits component visual hierarchy
- [ ] **Positioning** - Ensure badge doesn't interfere with component usability
- [ ] **Accessibility** - Add ARIA labels when badge meaning isn't obvious

- [ ] **Theming** - Verify badge styling works with component theme
