## 🎯 Design Patterns

### Status Indicators
spectrum-badge excels at communicating status across the interface:

```html
<!-- System status -->
<spectrum-badge text="Online" variant="success"></spectrum-badge>
<spectrum-badge text="Maintenance" variant="warning"></spectrum-badge>
<spectrum-badge text="Offline" variant="danger"></spectrum-badge>

<!-- User status -->
<spectrum-badge text="●" variant="success" circular></spectrum-badge>
<spectrum-badge text="●" variant="warning" circular></spectrum-badge>
<spectrum-badge text="●" variant="secondary" circular></spectrum-badge>
```

### Notification Counts
Perfect for displaying notification counts and numerical indicators:

```html
<!-- Notification badges -->
<spectrum-badge text="5" variant="danger" circular></spectrum-badge>
<spectrum-badge text="99+" variant="danger" circular></spectrum-badge>
<spectrum-badge text="12" variant="warning" circular></spectrum-badge>
```

### Selection Markers
Ideal for marking selected items in galleries and lists:

```html
<!-- Selection indicators -->
<spectrum-badge text="✓" variant="primary" circular></spectrum-badge>
<spectrum-badge text="1" variant="primary" circular></spectrum-badge>
<spectrum-badge text="Selected" variant="primary" size="small"></spectrum-badge>
```

## 🔧 Technical Integration

### Component Architecture
- **Atomic Design**: spectrum-badge is a pure atomic component with no internal dependencies
- **Flexible API**: Supports both property-based content (`text`) and slotted content
- **Theme Integration**: Uses Spectrum CSS custom properties for consistent theming
- **Responsive**: Adapts to different screen sizes and contexts

### Event Handling
spectrum-badge is a display component and does not emit events. Parent components handle user interactions:

```html
<!-- Parent handles click events -->
<div @click=${this.handleSelection}>
  <spectrum-badge text="✓" variant="primary" circular></spectrum-badge>
</div>
```

### Styling Integration
Works seamlessly with parent component styling:

```css
/* Parent component positioning */
.image-container {
  position: relative;
}

.selection-badge {
  position: absolute;
  bottom: 8px;
  left: 50%;
  transform: translateX(-50%);
}
```
