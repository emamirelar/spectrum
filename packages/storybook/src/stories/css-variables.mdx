# 🎨 CSS Variables Reference

This document provides a comprehensive reference of all CSS custom properties (CSS variables) available in the UNOPS Spectrum Design System. These variables enable consistent theming, styling, and maintainability across all Spectrum components.

---

## 📋 Overview

CSS Variables in the Spectrum Design System are organized into several categories:

- **UNOPS Brand Colors**: Core organizational colors
- **Spectrum System Colors**: Design system semantic colors
- **Material Design 3 Theme Colors**: Dynamic theme colors (can be overridden by spectrum-theme/spectrum-wallpaper)
- **Typography**: Font families, sizes, and weights
- **Material Icons**: Icon font settings
- **Spacing & Layout**: Padding, spacing, and sizing tokens
- **Borders & Shapes**: Border radius and border widths
- **Animation**: Timing and duration values
- **Component-Specific**: Special-purpose component variables

## 🔄 Dynamic Theme Colors

The Material Design 3 theme colors (`--spectrum-color-*`) can be dynamically overridden by:

- **spectrum-theme**: Applies theme colors based on selected theme mode
- **spectrum-wallpaper**: Extracts colors from wallpaper images and applies them to the theme

These components coordinate via document-level events to ensure consistent theming throughout the application.

### Theme Coordination Example

```html
<!-- Theme component with wallpaper coordination -->
<spectrum-theme 
  wait-for-wallpaper="true"
  auto-load-fonts="true">
</spectrum-theme>

<!-- Wallpaper component with color extraction -->
<spectrum-wallpaper 
  image-url="/path/to/wallpaper.jpg"
  preload-colors="true"
  signal-ready="true">
</spectrum-wallpaper>
```

When both components are present:
1. Wallpaper extracts dominant colors from the image
2. Theme waits for wallpaper color extraction
3. Extracted colors are applied to `--spectrum-color-*` variables
4. All components using these variables automatically update

## 📊 Color Scale Guidelines

### Using Color Scales

The color scales (50-900) follow Material Design color system conventions:

- **50**: Lightest shade - use for backgrounds, hover states
- **100-400**: Light to medium shades - use for surfaces, containers
- **500**: Base color - primary brand representation
- **600-900**: Medium to darkest shades - use for text, emphasis, shadows

### Accessibility Considerations

When using colors, ensure proper contrast ratios:

- **Normal text**: Minimum 4.5:1 contrast ratio
- **Large text** (18pt+ or 14pt+ bold): Minimum 3:1 contrast ratio
- **UI components**: Minimum 3:1 contrast ratio

Use the WCAG contrast checker tools or browser DevTools to verify contrast ratios.

### When Adding New CSS Variables

When adding new CSS variables to the design system:

1. **Update Source Files**: Add variables to `spectrum-variables.css` or `spectrum-colors.css` in `/packages/core/src/styles/`
