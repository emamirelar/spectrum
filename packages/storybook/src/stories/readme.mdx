# 🌈 UNOPS Spectrum Design System

**Spectrum** is UNOPS's comprehensive design system that provides a unified set of reusable components, design tokens, and patterns to create consistent, accessible, and beautiful user interfaces across all UNOPS digital products.

Built with modern web technologies and Material Design 3 principles, Spectrum empowers teams to build high-quality user experiences while maintaining design consistency at scale.

---

## ✨ What is Spectrum?

Spectrum is more than just a component library—it's a complete design system that includes:

### 🎨 **Design Foundation**
- **Material Design 3 Color System**: Dynamic theming with adaptive colors
- **Typography Scale**: Harmonious text styles optimized for readability
- **Spacing System**: Consistent spatial rhythm using design tokens
- **Accessibility First**: WCAG 2.1 AA compliant components by default

### 🧩 **Component Library**
- **15+ Production-Ready Components**: From simple buttons to complex data visualizations
- **Framework Agnostic**: Use with React, Vue, Angular, or vanilla JavaScript
- **TypeScript Support**: Full type safety and excellent developer experience
- **Customizable**: Extensive theming and configuration options

### 🏗️ **Architecture**
- **Web Components (Stencil)**: Native browser support, framework independent
- **Output Targets**: Automated React, Vue, and Angular bindings
- **Tree Shakeable**: Import only what you need for optimal bundle sizes
- **Modern Build Pipeline**: Vite, TypeScript, and advanced optimizations

## 🚀 Quick Start

### **Installation**

**For React/Next.js:**
```bash
npm install @unops-itg-npm/cpit-spectrum
```

**For Vue/Nuxt:**
```bash
npm install @unops-itg-npm/cpit-spectrum
```

**For Angular:**
```bash
npm install @unops-itg-npm/cpit-spectrum
```

### **Basic Usage**

**React Example:**
```jsx
import { SpectrumButton, SpectrumTheme } from '@unops-itg-npm/cpit-spectrum/react';

function App() {
  return (
    <SpectrumTheme color="#1976d2">
      <SpectrumButton 
        variant="primary" 
        onClick={() => console.log('Clicked!')}
      >
        Get Started
      </SpectrumButton>
    </SpectrumTheme>
  );
}
```

**Vue Example:**
```vue
<template>
  <spectrum-theme color="#1976d2">
    <spectrum-button 
      variant="primary" 
      @buttonAction="handleClick"
    >
      Get Started
    </spectrum-button>
  </spectrum-theme>
</template>
```

**Vanilla HTML:**
```html
<spectrum-theme color="#1976d2">
  <spectrum-button variant="primary">
    Get Started
  </spectrum-button>
</spectrum-theme>
```

## 🔧 Development Workflow

### **1. Clone & Setup**
```bash
git clone [repository-url]
cd cpit-spectrum
npm install
```

### **2. Build Core Components**
```bash
cd packages/core
npm run build
```

### **3. Start Development**
```bash
cd packages/storybook
npm run storybook  # Full dev environment with hot reload
# or
npm run storybook.run  # Storybook only
```

### **4. Generate New Components**
```bash
cd packages/core
npm run generate <component-name>
```

## 🎯 Design Philosophy

### **Consistency at Scale**
Spectrum ensures visual and functional consistency across all UNOPS applications, reducing cognitive load for users and development overhead for teams.

### **Accessibility by Default**
Every component is built with accessibility as a core requirement, not an afterthought. We follow WCAG 2.1 AA guidelines and test with real assistive technologies.

### **Performance First**
Components are optimized for performance with:
- Lazy loading and code splitting
- Minimal runtime overhead
- Tree-shakeable imports
- Optimized bundle sizes

### **Developer Ergonomics**
We prioritize developer experience with:
- Comprehensive TypeScript support
- Clear documentation and examples
- Intuitive APIs and naming conventions
- Excellent tooling integration
