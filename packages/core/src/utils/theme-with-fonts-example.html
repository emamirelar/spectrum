Configuration Options

Theme Component Properties:

  • auto-load-fonts: Enable/disable automatic font loading (default: true)
  • preload-fonts: Preload fonts via link elements (default: true)
  • font-load-timeout: Timeout in milliseconds (default: 3000)
  • debug: Show font loading indicator and debug logs (default: false)
