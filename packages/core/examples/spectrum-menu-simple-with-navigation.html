  • Your HTML attribute usage now works perfectly
  • Backwards compatible with programmatic usage

🆕 Direct Navigation Feature

  • New directNavigation boolean prop

  • When false (default): only emits events, no navigation
  • Events are still emitted in both modes for custom handling
