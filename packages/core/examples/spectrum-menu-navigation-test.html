Spectrum Menu - Direct Navigation Feature Test

New Feature: directNavigation
The spectrum-menu component now supports automatic browser navigation with the directNavigation attribute. When set to true, clicking menu items will navigate directly to their href URLs in the current tab.

Test 1: Default Behavior (directNavigation = false)

This menu only emits events when items are clicked. No direct navigation occurs.

Code:

<spectrum-menu 
    orientation="horizontal"
    directNavigation="false"
    items='[
        {"label": "Google", "href": "https://www.google.com", "icon": "search"},
        {"label": "GitHub", "href": "https://www.github.com", "icon": "code"},
        {"label": "Stack Overflow", "href": "https://stackoverflow.com", "icon": "help"}
    ]'>
</spectrum-menu>

Test 2: Direct Navigation Enabled (directNavigation = true)

⚠️ Warning: Clicking these menu items will navigate away from this page to the actual URLs!
This menu will navigate directly to the href URLs when items are clicked. Events are still emitted before navigation.

Code:

<spectrum-menu 
    orientation="horizontal"
    directNavigation="true"
    items='[
        {"label": "Example.com", "href": "https://www.example.com", "icon": "public"},
        {"label": "W3C", "href": "https://www.w3.org", "icon": "language"},
        {"label": "MDN", "href": "https://developer.mozilla.org", "icon": "school"}
    ]'>
</spectrum-menu>
