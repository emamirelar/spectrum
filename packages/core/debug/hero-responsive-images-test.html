Spectrum Hero - Responsive Images Test

Testing srcset and sizes support for responsive image delivery

Test Configuration

This test demonstrates responsive images using:

  • srcset: Multiple image sources at different widths
  • sizes: Viewport-based size hints for optimal image selection
  • src: Fallback image for browsers without srcset support
💡 Test Instructions: Resize your browser window and check the Network tab in DevTools to see different images being loaded based on viewport size.
