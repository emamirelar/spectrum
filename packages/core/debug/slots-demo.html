🎯 Available Slots

The spectrum-app-layout component provides 6 slots for flexible content composition:

  • logo: Custom logo content in header left
  • header-content: Additional header elements in center area
  • profile: User profile/menu in header right
  • sidebar: Navigation content in collapsible sidebar
  • (default): Main application content
  • footer: Footer content at bottom

🎨 Customization

Each slot can be fully customized with your own HTML, CSS, and JavaScript. You can also use other Spectrum components within slots.

<div slot="logo">
  Your content
</div>

📖 Implementation Guide

To use slots in your application, simply add content with the corresponding slot attribute:

<spectrum-app-layout>
  <!-- Logo slot -->
  <img slot="logo" src="/logo.svg" alt="Logo" />
  
  <!-- Header content slot -->
  <div slot="header-content">
    <input type="search" placeholder="Search..." />
  </div>
  
  <!-- Profile slot -->
  <div slot="profile">👤 User Name</div>
  
  <!-- Sidebar slot -->
  <nav slot="sidebar">
    <a href="#home">🏠 Home</a>
    <a href="#about">ℹ️ About</a>
  </nav>
  
  <!-- Main content (default slot) -->
  <div>
    <h1>Welcome</h1>
    <p>Your main content goes here.</p>
  </div>
  
  <!-- Footer slot -->
  <div slot="footer">© 2024 Your Company</div>
</spectrum-app-layout>

For more detailed examples and best practices, see the SLOTS_GUIDE.md documentation.
