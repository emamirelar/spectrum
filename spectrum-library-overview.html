Dependency Levels

account_tree Dependency Hierarchy

Components are organized in layers. Higher levels depend on lower levels.

Level 0 — Foundation
spectrum-theme

Level 1 — Atomic (no internal dependencies)
spectrum-avatar, spectrum-button, spectrum-chip, spectrum-switch, spectrum-badge
spectrum-toast, spectrum-panel, spectrum-context-menu, spectrum-wallpaper
spectrum-menu, spectrum-media-library, spectrum-text-input, spectrum-card
spectrum-chart (chart.js), spectrum-map (leaflet/maplibre)

Level 2 — Composed (1–3 internal deps)
spectrum-accordion → chip
spectrum-search-input → button
spectrum-rail-item → button
spectrum-collapsible-list → context-menu
spectrum-select → button
spectrum-dialog → button
spectrum-search-results → button
spectrum-hero → button
spectrum-wizard → button, chip, switch
spectrum-image-gallery → button, badge, panel
spectrum-cookie-compliance → button, toast, dialog

Level 3 — Complex (multiple internal deps)
spectrum-rail → button, search-input, collapsible-list, rail-item, context-menu
spectrum-conversation-panel → accordion, button, chip, panel
spectrum-dashboard → @stencil/store, widget-host, filter-panel, breadcrumb, score-card

Level 4 — Layout Shells (pure layout, no component deps)
spectrum-app-layout, spectrum-application-layout
spectrum-flex, spectrum-grid, spectrum-stack, spectrum-cluster, spectrum-container, spectrum-sidebar
