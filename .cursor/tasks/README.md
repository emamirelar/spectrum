# Code Review Tasks Directory

This directory contains task files generated by the Code Review Rule. Each file represents a structured list of issues found during code review that can be resolved using Cursor's task system.

## File Naming Convention
- Format: `code-review-YYYY-MM-DD-HHMMSS.md`
- Example: `code-review-2024-12-15-143022.md`

## Task File Structure
Each task file contains:
- **Critical Issues**: Must be fixed before merge
- **Major Issues**: Should be addressed
- **Minor Issues**: Consider fixing for code quality
- **Enhancements**: Future improvement opportunities

## Using Task Files
1. Open the task file in Cursor
2. Use Cursor's task tracking to check off completed items
3. Click on file paths to navigate directly to issues
4. Follow the provided fix instructions

## Retention Policy
- Keep recent task files (last 30 days)
- Archive or delete older task files as needed
- Generated files are git-ignored by default

## Integration with Code Review Rule
Task files are automatically generated when running:
- "Review my changes"
- "Run code review on the entire codebase"
- Other code review commands

Each task includes:
- **File path and line number** for direct navigation
- **Rule reference** that triggered the issue
- **Specific fix instructions**
- **Impact assessment**
- **Priority level**
